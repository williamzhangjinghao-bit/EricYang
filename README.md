# 杨启航个人主页

这是一个轻量静态网站项目，仅包含 HTML、CSS 和少量原生 JavaScript，无需安装依赖、数据库或后端。

## 本地预览

在文件管理器中打开本文件夹，双击 `index.html`，即可用浏览器预览。也可以将 `index.html` 拖到浏览器窗口中。

## 打印或导出 PDF

网页顶部或页面底部点击“打印 / 保存 PDF”，在浏览器打印窗口选择“存储为 PDF”。打印样式会隐藏导航与按钮，并调整纸张边距和分页。

## 发布到互联网

项目可部署为静态网站。简单方式是使用 Netlify Drop：

1. 打开 [Netlify Drop](https://app.netlify.com/drop)。
2. 将 `yang-qihang-resume` 项目文件夹或打包文件 `yang-qihang-resume.zip` 拖到上传区域。ZIP 在项目文件夹的上一级目录。
3. 部署完成后，复制 Netlify 提供的 `*.netlify.app` 地址分享。
4. 更新网站时，再次上传项目文件夹。

公开发布前请确认愿意公开页面中的姓名、手机号、邮箱、工作经历与教育经历。当前页面包含你简历中提供的手机号和邮箱。Netlify 上传和部署尚未执行，因此目前没有公开网址。
